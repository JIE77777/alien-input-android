## 本轮结果

- 移除构建中自制 `alien-keyboard.fragment` 的使用，采用 **rime-pure 完整同文风增强版主题和四叶草九宫格方案**，包括数字、英文大小写、编辑、标点、符号与表情页面。
- 上游锁定到 `93601c6774385e6830ed3e3120b4e63888efc983`。词库、语言模型、原始主题、许可证和 SHA256 均保存在 `vendor/rime-pure/`。
- 保留全拼与小鹤双拼。旧 `alien_t9` ID 转为四叶草兼容别名，避免已有设置突然找不到输入方案。键盘数字编码也随现成方案改为真正的 2–9。
- 图片固定 **592 像素宽，每行五个完整字形**；1–5 个高 144，6–10 个高 256，11–15 个高 368。字形保持 100×100，字位 112×112，四周统一留白。每一行均水平居中，含不足五个字形的末行，超出五个自动换行，最多 120 个字形。
- 预览与复制图共用同一渲染路径。默认米黄字／黑底，九组游戏配色放在 **设置 → 虚拟键盘 → 外星图片配色**，不占首页或输入法主界面。
- 输出按透明度遮罩着色，候选和草稿采用适合浅色界面的深色显示，不会因原图是白色而看不清。
- 游戏原始字形本轮只导出已核对的 **大 F0001、你 F0835、食物 F1047**。完整 1344 项映射清单记录 reviewed / pending；其余 1341 项继续使用原素材。本轮不宣称已完成全部字形替换。
- PNG 中的字形编码与词组边界保留；布局和颜色不改变语义 ID。

## 现成主题的兼容处理

布局沿用上游，不另写一套九宫格。`tools/prepare_rime_pure.py` 隔离以下适配：

1. 固定上游 YAML 的别名和重复键结果，保存机械转换的 JSON 快照；展开当前宿主不支持的数组索引补丁。
2. 使用当前同文的符号页、剪贴板和字符集切换命令；纠正上游中英文切换标签及返回路径。
3. 九宫格数字按键加命名动作，避免运行时把 ABC 等标签显示为数字。
4. 对默认与同文风两个旧主题 ID 同步提供完整布局，另保留增强版主题 ID，防止引擎与布局不匹配的旧问题重现。
5. 删除四个没有被任何按键引用、目标页面不存在的上游预设动作。
6. 禁用未安装的可选 emoji 转写词典依赖；主题自身的完整符号／表情面板不受影响。不安装上游个人 custom_phrase 文件。
7. 实机检查暴露旧方案 ID 未参与 Rime 部署：改为从上游生成完整旧 ID 配置，并作为四叶草的兼容依赖部署；没有增加重复的默认方案选项。
8. 实际打开键盘暴露工具栏透明色 0 被转成十进制文本的问题：对配色表、工具栏和按键的内联颜色统一保留十六进制颜色语义，加入真实主题解码回归断言后实机复验通过。

英文、数字、编辑页是上游现成页面；不是“在旧自制键盘补几个按钮”。完整默认中文 26 键布局也来自同一上游主题。

## 使用和后续维护

安装覆盖原“外星同文·测试”。首次加载四叶草词库需要部署；如果升级后仍见旧布局，先在应用中重新部署，主题选择“同文风增强版 · 四叶草九宫格”，方案选择“四叶草九宫格”。本轮未代替用户清空或改写个人词库。

九宫格直接点“符”打开符号分类，“123”进入数字页，“En”进入完整英文键盘，“编辑”打开光标与复制粘贴等操作。用“中文”或“返回”回到中文九宫格。

构建：`source ~/project/dev-env/android-env.sh` 后执行 `bash tools/build-trime.sh`。资源已固定在本地，普通重建不需要下载游戏或安装 Unity 编辑器。解析环境仍在共享 dev-env 中。

下一步继续审核剩余字形映射，并根据实际日常输入反馈改善候选体验；不需要以截图方式验收聊天排版。
