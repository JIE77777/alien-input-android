# 四字位、统一字形与数字输入修正

日期：2026-11-12（Asia/Shanghai）。开发目录：`/Users/jie/project/alien-input-android`。

## 本版行为

- 一行最多四个完整字形，固定宽 480 像素，单行高 208；两行高 256，后续每行增加 112。单行采用微信 A/B/C 实测中完整显示、留白适中的 B 比例，约 2.31∶1。
- 两、三字形词组保持完整，不跨行拆开；优先用最少行，再平衡各行字数，保持阅读顺序。五个单字排为 3＋2，六个单字排为 3＋3。各行居中，整组内容垂直居中。超过整行容量的长数字组合只能拆行；最多保留 120 个字形。
- 预览与复制、插图、分享均使用同一份词组快照。图片仍保留原有字形 ID 与词组边界。
- 1344 个静态字形全部使用同源 v6.12.4 素材，统一透明度曲线和抗锯齿处理；生产包不再混入三张游戏原始纹理。候选、草稿、预览和输出共用这些资源。
- 新增十进制整数查询：0、1、8、9、1234、负整数及全角数字均可查询。数字按数值转为上游七进制数词，不是逐位字符替换。最多 18 位十进制整数。已有单字形数词优先使用静态资源；高次幂按上游规则生成上横线数词。
- `1234 = 3×343 + 4×49 + 1×7 + 2`，对应 `F1321,F1327,F1304,F1310`。数字候选标记“数值”；四字形候选完整显示，更长的候选注明字形数。动态数字不写入用户词频，避免累积大量一次性数字记录。
- 补了草稿自动滚到新选中项、预览字形数／行数、关闭预览释放图片引用。
- 真实触屏发现旧预览窗口抢焦点，造成键盘关闭和稿件丢失；现改为不抢输入焦点的弹窗，提供“关闭”，并在输入会话结束时清理弹窗。

## 字形处理和游戏解析留档

`tools/prepare_uniform_glyphs.py` 校验 `glyph-map.json` 中全部原始素材哈希，在构建时统一执行 alpha levels 24–160（4 倍采样处理后回到 100×100），只处理遮罩覆盖度，不猜测笔画或改变字形身份。每个字形检查非空、实心像素和原有核心笔画保留，打包后再按 manifest 校验 1344 个输出哈希。清单位于 APK 的 `assets/alien/glyph-style.json`。

这是完整旧字库的一致化处理，**不是全量游戏原纹理替换，也不是矢量重绘**。游戏原始素材、三项已核对映射、其余待核对项、资源哈希、颜色预设和解析脚本仍保存在 `research/game/`。没有按视觉近似值猜映射。完整的游戏素材映射仍待后续审核。

数字转换与生成规则来自固定的 `alien-input v6.12.4/src/js/numbers.js`，源码与哈希保存在 `vendor/alien-input-numbers/`。只移植整数编码及其所需的正幂横线数词，不声称接入上游全部小数、分数、科学记数法或日期系统。PNG 编码允许有界的 `N1P4` 等生成 ID；旧版只认识 F ID 的解析器不能读取含这些新 ID 的消息。

## 安装与使用

最终版已覆盖安装到设备 d4d4b8ea，包名 `io.github.alieninput.trime.debug`。临时检查包已卸载，保留用户当前选择的外星同文输入法并返回微信。没有改写个人词库。

数字使用：展开“外星” → 切换键盘数字页（九宫格的“123”或 26 键的“?123”）→ 输入 1234 → 点“1234”候选 → 复制图。中文仍先选定 Rime 中文候选，再点外星候选。小数、电话号码按逐位表示、日期格式暂未作为动态转换模式实现；完整字库不等于所有同义说法都已覆盖。
