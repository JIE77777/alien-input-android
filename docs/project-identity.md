# 项目名称与介绍

## 名称

- 中文：外星人输入法。
- 英文：Alien Input for Android。
- 仓库：JIE77777/alien-input-android。
- 副标题：为《外星来信》玩家制作的 Android 输入法。
- 简短介绍：用熟悉的词语查找外星文字，组合成自己的消息。

名称直说产品用途，副标题补足与游戏的关系。英文沿用 Alien Input 的上游识别，并加上平台说明；README 明确链接原作者项目，避免把已有成果写成独立原创。中文名是社区工具的名称，不是游戏中的专有名词或官方产品名。

## 对外介绍

外星人输入法是一款为《外星来信》玩家制作的 Android 输入法。日常中文输入由 Trime / Rime 提供；展开外星面板后，可以用中文或英文查找词语、选择字形、逐词组合，再把整条消息作为图片复制到聊天应用。当前专注于书写与表达，不承诺整句翻译。

GitHub About：外星人输入法｜《外星来信》玩家的 Android 书写工具。基于 Trime/Rime，支持中英查词、外星字形组合与图片输出。

## 与游戏的联系

游戏让玩家从信号、数词与字形中理解一种语言。本项目延续的是“理解后尝试使用”的体验：查询概念、挑选字形、组织自己的表达。不要把它描述成中文换皮字体，也不要把人工释义或字形组合包装成已经验证的游戏语法。

视觉沿用几何字形、简洁留白、前景与背景分离的方向。米黄字／黑底是默认选择，游戏本身支持换色。当前使用上游全套字形的一致处理结果，不能声称已完整复刻游戏渲染。

首页先呈现用途与操作，再提供开发细节。释义与示例可能透露游戏解谜内容，样例折叠展示。首页不使用未经核对的外星语写项目名称，不杜撰母星名称、民族或通信协议。

## 首版发布

正式项目展示名为“外星人输入法”；调试包在手机中显示“外星人输入法·测试”。版本 v0.2.0-alpha.2 重新构建，保留包名与原调试签名。此前 v0.2.0-alpha.1 标签作为源码快照保留，不移动。

本次发布区分此前实机测试与新包构建、签名、字形校验；新包实机验证留待设备连接后进行。
