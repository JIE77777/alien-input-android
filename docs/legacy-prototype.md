# Alien Input Android

基于 [feierbuqiu/alien-input v6.12.4](https://github.com/feierbuqiu/alien-input/releases/tag/v6.12.4) 的社区 Android 系统输入法。Android 7.1（API 25）及以上，原生 Java 实现，无第三方运行时依赖，无网络权限。

## 这版能做什么

- 系统 IME：安装后可在系统设置启用，在应用输入框中切换使用。
- 完整 1,344 字形、2,033 标准拆码、94 主副字根；候选分页无截断。
- 920 个上游词组的完整、首根简码及逐字替代码组合匹配。
- 主根 / 副根切换、字根翻页、实体键盘输入、候选学习、退格与英文直输。
- 图片模式：把候选加入图片稿，最多 120 字，8 字一行，生成白底 PNG。
- 使用 Android Commit Content 插入 PNG；不支持的应用可使用系统分享。
- 释义模式：输出上游研究释义；编号模式：输出 `[F0001]` 形式的稳定字形 ID。
- 启用引导、支持 PNG 输入的试写框、许可查看和学习数据清除。

外星字在上游是位图，不是 Unicode 字符。本项目不会伪造能够在任意应用显示的文字编码。中文释义不是官方翻译，图片插入需要接收应用支持，未声明 PNG 支持时不会冒充输入成功。普通应用可以接收释义或编号文本。

## 本地环境

源码：`~/project/alien-input-android`。共享环境：`~/project/dev-env`。

```sh
source ~/project/dev-env/android-env.sh
cd ~/project/alien-input-android
./tools/build-local.sh
```

脚本先执行码表测试，再用官方 `aapt2`、`javac`、`d8`、`zipalign`、`apksigner` 构建调试 APK，输出：

```text
build/local/alien-input-android-0.1.0-debug.apk
```

需要 JDK 17、Android SDK platform 35、build-tools 35.0.0。密钥在 `dev-env/keys/alien-input-debug.jks`，不放源码中。测试签名仅适用于个人安装测试，正式发布应另建发行密钥。

同时提供标准 Android Gradle 工程（AGP 8.7.3 / compileSdk 35），可用 Android Studio 打开。仓库当前不含 Gradle Wrapper；使用本地构建脚本无需下载 Gradle。

## 安装与使用

1. 把 APK 传到 Android 手机，允许用于安装的应用“安装未知应用”，完成安装。
2. 打开「Alien 外星输入法」，点击启用按钮，在系统设置打开它。
3. 点击切换按钮，选择「Alien 外星输入法」。
4. 点击试写框。先点字根，再选候选；Shift 切换副根。也可直接浏览候选。试例：第 2 页的 `s / 大` 字根可选出「大」，连续点两次可选出「大/多/很」。
5. 默认图片模式，点「插入」将图放入试写页；其他应用是否支持取决于其输入框。
6. 「输出模式」在图片、释义、编号三种模式间轮换。模式切换前需处理图片稿。

`⌫` 优先删除未完成的字根，其次删除图片稿末字，最后删除目标输入框文字。空格在组字时选首候选；回车先选候选，再插图，无稿件时执行目标输入框动作或换行。Tab 翻候选页。

## 数据与边界

- 无网络权限、不读取剪贴板、不自动记录输入框内容。
- 学习仅记录选中过的字形 / 词组计数，存在应用私有 SharedPreferences。
- 密码框及声明 `IME_FLAG_NO_PERSONALIZED_LEARNING` 的输入框不学习。
- 图片稿保存在当前输入会话内，切换输入框或退出输入会话会清空。分享前生成的 PNG 留在缓存，供接收应用读取；下一次导出时清理超过 7 天的缓存。
- 不实现上游完整编辑器、自定义布局、扩展模式结构推断、稿件备份格式及动态数字/时钟功能。
- 本版是原型测试版；匹配优先级为精确/前缀距离、本机频次、上游频次、编号，未声称完全复现上游排序。

## 源码与验证

- `Codebook.java`：平台无关的码表与词组动态规划匹配。
- `AlienIme.java`：InputMethodService、触屏键盘和输出会话。
- `ImageProvider.java`：只读、未导出、按 URI 授权的图片提供器。
- `MainActivity.java`：启用引导与图片输入验证页面。
- `tools/import_upstream.py`：从上游公开源码重新提取 assets。
- `tests/CodebookTest.java`：遍历全部字形拆码和词组全码 / 简码 / 替代码，并验证排序、无效输入、长度限制和学习。

必须在真机或模拟器补测：系统启用与切换、横竖屏、软键盘遮挡、导航栏、中文/编号提交、PNG 接收、拒收后保留稿件、系统分享、密码框及目标聊天应用兼容性。自动码表测试不等同于真机验收。
