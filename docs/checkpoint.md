# 当前阶段：v0.3.0-beta.1

围绕安卓的“写消息、读图片、继续编辑”收敛。日常输入沿用 Trime/Rime，默认九宫格。

本版交付：产品首页、独立写消息页面、与键盘共用的图片稿、本地词语查询、图片稿持久保存、居中换行、数字表达、复制图片、相册/剪贴板读图和候选确认。

后续优先处理真实使用反馈、识别性能和机型适配。任意聊天截图定位、更广泛的字形风格、Linux 和同步留在后续；水印保留为研究，不随本版默认输出。

先前阶段记录见 [alpha.2 存档](checkpoint-alpha2.md)，语言和语义映射讨论见 [探索存档](exploration-archive.md)。
