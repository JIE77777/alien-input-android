# Android MVP 阶段收敛：0.2.0-alpha.2

目标是可持续试用的安卓测试版。此阶段功能冻结，优先修复日常使用反馈中的稳定性和可用性问题，不继续扩展输入法基座或完整翻译系统。

## 已验收

- Trime / Rime 基座，现成四叶草九宫格、全拼与小鹤双拼。
- 普通中文输入与可切换的外星逐词候选、组合草稿、替换删除。
- 1344 个静态字形、2264 个词条，统一图形处理与颜色设置。
- 480×208 单行输出、四字位上限、词组换行与居中。
- 整数数值转换、PNG 编码、复制图片与预览。
- 前一构建通过 1575 项设备检查及实际数字键盘、预览保稿验证；本次 alpha.2 改名重构建，新包实机验证待补。完整记录见 four-slot-numbers-update.md。

## 暂缓

- 全句语义翻译及大规模同义词扩展。
- 游戏原始纹理的全量对应审核与矢量字形系统。
- 小数／日期／电话号码逐位模式、图片导入恢复界面。
- Linux 和多端同步。

## 当前边界

游戏原图映射只核对了少数项目；生产资源采用整套旧字库统一处理。数字动态转换支持最多 18 位十进制整数。微信尺寸结论来自本机当前显示设置。长时间主力使用、其他机型和所有聊天应用尚未完整验证，因此版本标为 alpha。

## 仓库组成

提交自研源码、词典与字形、上游许可证、固定版本清单、Trime 接入补丁、测试和构建脚本。外部 Trime 工作树与大型语言模型由 bootstrap 恢复。缓存、设备截图、签名密钥、个人环境配置和原始游戏研究文件不提交；原始研究资料继续保留在本机。

## 仓库复现检查

从仅含 Git 暂存文件的干净目录恢复固定 Trime 源码、接入补丁与四叶草依赖，完成全新 APK 构建（51 个任务全部执行）。首轮整理待上传源码约 4.16 MiB；未包含编译产物、签名密钥、环境目录或原始游戏研究文件。目标仓库为 JIE77777/alien-input-android；每次发布必须核对实际登录账号及仓库所有者。
