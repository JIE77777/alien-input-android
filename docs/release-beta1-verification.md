# v0.3.0-beta.1 验证记录

日期：2026-11-17。设备：Android 16 / arm64-v8a。

本版以 Beta 预发布形式发行，已安装到设备。保留辅助首页，核心写字、读图与候选确认在键盘插件内完成。

## 核心与原生识别

- 9787 项词典与查询检查、53009 项四槽排版检查、19298 项整数转换与数值查询检查通过；PNG 编码与词组边界往返通过。
- Android 原生读图检查：1658 张样本，1635 张全部自动确认且序列正确，21 张进入候选确认，2 张空白对照拒绝；没有自动确认的误认。
- 样本包含全部 1344 个静态字形、108 种动态数字字形、31 张 Android 多行/整数消息及其 PNG、JPEG 和半尺寸版本，以及 3 张此前实际经微信处理的归档图片。
- 两张半尺寸 18 位整数图的首选序列正确，个别密集数字需确认。验收明确区分自动确认与交互确认，没有放低生产识别阈值。
- 预计算模板后的全量识别平均 63 ms / 张，最长 3156 ms；首次模板加载 691 ms（此前约 4966–7802 ms）。1658 张样本的判定数量不变，耗时是本设备记录，不视为跨机型性能保证。

## 输入法体验

- 写字 / 读图分区；图片稿旁提供预览与复制，复制后显示「已复制 ✓」及粘贴提示。
- 1583 项 Android 16 设备检查通过，覆盖九宫格、全拼、双拼、词语/数字、持久稿件、模式切换和复制反馈。
- 独立键盘读图检查覆盖候选确认、整数合并及追加时保留已有稿件；实机验证剪贴板读取，以及相册选取 123456 样张后自动返回键盘并显示结果。
- 首页简化后已覆盖安装，实际验证「打开读图」进入相册/剪贴板读取页、「打开键盘」使试写框获得焦点；空稿不显示示例图。
- 冷启动方案同步修复：复现引擎 clover_jiugong / 布局 default 错配；修复后启动布局为 clover_jiugong，实按 64426 出现并上屏「你好」。英文、数字、密码输入框返回普通文本均恢复九宫格；再次覆盖安装启动复查。
- 截图与手机私人内容不作为发布附件。
