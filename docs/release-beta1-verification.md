# v0.3.0-beta.1 验证记录

日期：2026-11-17。设备：Android 16 / arm64-v8a。

## 核心与原生识别

- 9787 项词典与查询检查、53009 项四槽排版检查、19298 项整数转换与数值查询检查通过；PNG 编码与词组边界往返通过。
- Android 原生读图检查：1658 张样本，1635 张全部自动确认且序列正确，21 张进入候选确认，2 张空白对照拒绝；没有自动确认的误认。
- 样本包含全部 1344 个静态字形、108 种动态数字字形、31 张 Android 多行/整数消息及其 PNG、JPEG 和半尺寸版本，以及 3 张此前实际经微信处理的归档图片。
- 两张半尺寸 18 位整数图的首选序列正确，个别密集数字需确认。验收明确区分自动确认与交互确认，没有放低生产识别阈值。
- 全量识别本轮平均 76 ms / 张，最长 3501 ms；首次模板加载 7802 ms。此轮同时有安装等设备活动，耗时只作记录，不视为性能保证。

- 1577 项设备集成检查通过，覆盖九宫格、全拼、双拼、外星查询、图片复制和共享图片稿。
- 独立产品 Activity 检查通过：查词不改稿、数值候选追加、图片剪贴板 URI、重新打开后保稿。
- 主应用覆盖安装成功，用户确认基础功能可用。此后界面调整另做了实机操作检查：新首页、写消息、九宫格输入“你”后选择外星候选、复制图片、剪贴板读回、加入图片稿并返回写消息页面。
